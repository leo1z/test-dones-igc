# Backup y Comparativa de Preguntas — Test Dones IGC (v7.1)

Este documento sirve como registro oficial y copia de seguridad de las **76 situaciones** del Test de Dones IGC, comparando la redacción original con la propuesta desculpabilizadora basada en **experiencias prácticas de servicio y vivencias diarias**, limpia y sin redundancias de palabras como "con frecuencia", ya que el indicador inferior (*Con poca frecuencia* ➔ *Con mucha frecuencia*) se encarga de esa medición.
